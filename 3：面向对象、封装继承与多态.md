4.

java中，如果一个子类同时继承了两个父类，若此时这两个父类中有同名的方法，那么在子类中创建对象调用这两个方法时就会发生冲突，即菱形冲突（简单来说，B 和 C 都继承自 A，如果 B、C 重写了 A 的同一个默认方法，D 实现 B、C 时就产生菱形冲突，源自c++的概念）

## Task5

public：所有类都可以访问，即公开信息

protected：仅相关类可以访问，给信息访问增加了权限

private：仅本类可以访问，使信息无法被直接访问

修改后的代码大致如下（基本符合常规适用场景）

```java
public class BankAccount {
    private String accountNumber;
    private String accountHolder;
    private double balance;
    private String password;

    public BankAccount(String accountNumber, String accountHolder, double initialBalance, String password) {
        this.accountNumber = accountNumber;
        this.accountHolder = accountHolder;
        if (validateAmount(initialBalance)) {
            this.balance = initialBalance;
        } else {
            this.balance = 0;
        }
        this.password = password;
    }

    public void deposit(double amount) {
        if (validateAmount(amount)) {
            balance += amount;
        }
    }

    public boolean withdraw(double amount, String inputPassword) {
        if (!validatePassword(inputPassword)) {
            return false;
        }
        if (!validateAmount(amount)) {
            return false;
        }
        if (balance >= amount) {
            balance -= amount;
            return true;
        }
        return false;
    }

    public boolean transfer(BankAccount recipient, double amount, String inputPassword) {
        boolean success = this.withdraw(amount, inputPassword);
        if (success) {
            recipient.deposit(amount);
        }
        return success;
    }

    public double getBalance() {
        return balance;
    }

    public String getAccountInfo() {
        return "账号：" + accountNumber + "，户名：" + accountHolder + "，当前余额：" + balance;
    }

    private boolean validatePassword(String inputPassword) {
        if(inputPassword == null){
            return false;
        }
        return this.password.equals(inputPassword);
    }

    private boolean validateAmount(double amount) {
        return amount > 0;
    }
}
```
